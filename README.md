# 🎨 Front-End — Interface Web

> Repositório contendo a interface do usuário para o catálogo de produtos e encurtador de links.

## 🚀 Sobre o Projeto
Este repositório armazena todos os arquivos estáticos e scripts de interface de usuário. A aplicação foi desenvolvida de forma responsiva para navegação entre categorias de produtos e interação com os serviços de encurtamento de URLs.

## ✍️ Autoria & Desenvolvimento
Este projeto foi **programado e estruturado 100% à mão por mim**. O uso de inteligência artificial limitou-se exclusivamente ao suporte teórico e de ideias; nenhum código foi gerado ou alterado diretamente por IA, garantindo controle total sobre a aplicação.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização, layout e responsividade.
* **JavaScript (ES6+):** Manipulação do DOM e requisições assíncronas para a API.
